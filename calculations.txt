PACE INDEX — CALCULATIONS REFERENCE
=====================================
All values displayed in the Pace Index tab and how they are computed.
Source files: server/src/controllers/paceIndexController.ts
              client/src/components/dashboard/projects/ProjectsList.tsx (PaceTab / FinancialTab)


════════════════════════════════════════════════════════════════
ABBREVIATIONS — FULL NAMES
════════════════════════════════════════════════════════════════

  Avg          — Average
  YTD          — Year To Date  (from January 1st up to the current month)
  proj.        — Projection  (estimated value at year end)
  Est.         — Estimated
  TND          — Tunisian Dinar  (Dinar Tunisien)
  Pct / pct    — Percentage
  m            — month  (index variable, e.g. consumed[m] = hours for month m)
  Jan          — January
  Apr          — April
  SUM          — Summation  (add all values in the set)
  COUNT        — Count  (number of items in the set)
  max          — Maximum  (take the larger of two values)
  round        — Round to nearest integer  (standard mathematical rounding)
  MS           — Milliseconds  (used in date arithmetic)
  coutHoraire  — Coût Horaire  (French: Hourly Cost / hourly rate per collaborator)
  Collab       — Collaborateur  (French: Collaborator / team member)
  h            — Heure  (French: Hour)
  h/month      — Hours per month
  TND/h        — Tunisian Dinars per Hour  (hourly financial rate)


════════════════════════════════════════════════════════════════
INPUTS (data stored per client per month in the database)
════════════════════════════════════════════════════════════════

  internalHours      — hours the firm allocates internally per month
  clientHours        — hours billed to the client per month (contract)
  consumed[m]        — actual hours consumed in month m (from timesheets)
  financialBudget    — full-year financial contract value in Tunisian Dinars (TND)
  Expert.coutHoraire — hourly cost rate (Coût Horaire) per collaborator


════════════════════════════════════════════════════════════════
STEP-BY-STEP DERIVATION FOR EACH DISPLAYED VALUE
════════════════════════════════════════════════════════════════

──────────────────────────────────────────────────────────────
1. MONTHLY PACE RATIO  (used internally, feeds Average Pace)
──────────────────────────────────────────────────────────────

  paceRatio[m] = consumed[m] / internalHours        (if internalHours > 0, else 0)

  Interpretation:
    < 0.85  → on track (green)
    0.85–1  → at risk  (yellow)
    > 1     → over budget (red)

  Only months that are past OR the current month WITH at least 1 consumed hour
  are included in downstream averages.


──────────────────────────────────────────────────────────────
2. AVG PACE  (Average Pace)  →  displayed as "87%"
──────────────────────────────────────────────────────────────

  pastPaceValues = [ paceRatio[m] for each elapsed/current month with data ]

  avgPace (Average Pace) = SUM(pastPaceValues) / COUNT(pastPaceValues)

  Displayed as:  round(avgPace × 100)  + "%"

  Example: months Jan (January) – Apr (April) with ratios 0.90, 0.85, 0.88, 0.84
    avgPace = (0.90 + 0.85 + 0.88 + 0.84) / 4 = 0.8675
    Display → 87%


──────────────────────────────────────────────────────────────
3. YTD CONSUMED  (Year To Date Consumed)  →  displayed as "27,8h"
──────────────────────────────────────────────────────────────

  ytdConsumed (Year To Date Consumed) = SUM( consumed[m]  for m = Jan (January) to current month )

  Displayed with 1 decimal, French locale (comma separator).


──────────────────────────────────────────────────────────────
4. ELAPSED MONTHS  (intermediate, not displayed directly)
──────────────────────────────────────────────────────────────

  elapsedMonths = max( COUNT(pastPaceValues), 1 )

  Example: running in April → elapsedMonths = 4 (January, February, March, April)


──────────────────────────────────────────────────────────────
5. REMAINING MONTHS  (intermediate, not displayed directly)
──────────────────────────────────────────────────────────────

  remainingMonths = 12 - elapsedMonths

  Example: elapsedMonths = 4  →  remainingMonths = 8


──────────────────────────────────────────────────────────────
6. YEAR-END PROJECTION (Year-end proj.)  →  displayed as "83,3h"
──────────────────────────────────────────────────────────────

  projectedYearEnd (Projected Year End) =
    ytdConsumed (Year To Date Consumed)
    + ( avgPace (Average Pace) × internalHours × remainingMonths )

  Logic:
    - Take what has already been consumed (Year To Date).
    - Project future months using the current average burn rate
      applied to the firm's internal monthly budget.

  Example:
    ytdConsumed     = 27.8h (27.8 Hours)
    avgPace         = 0.87  (Average Pace = 87%)
    internalHours   = 6.5h/month (6.5 Hours per month)
    remainingMonths = 8

    projectedYearEnd = 27.8 + (0.87 × 6.5 × 8)
                     = 27.8 + 45.24 ... ≈ (actual numbers in the app)

  Displayed with 1 decimal, French locale.


──────────────────────────────────────────────────────────────
7. TOTAL CLIENT HOURS (Annual)  →  displayed as "Billed to client: 96,0h"
──────────────────────────────────────────────────────────────

  totalClientHours (Total Client Hours) = clientHours × 12

  Example: clientHours = 8h/month (8 Hours per month)  →  totalClientHours = 96h (96 Hours)


──────────────────────────────────────────────────────────────
8. YTD CLIENT GAIN  (Year To Date Client Gain)  →  displayed as "+12,3h"
──────────────────────────────────────────────────────────────

  For each elapsed/current month m:
    clientGain[m] = clientHours - consumed[m]

  ytdClientGain (Year To Date Client Gain) =
    SUM( clientGain[m]  for m = Jan (January) to current month )

  Equivalently:
    ytdClientGain = (clientHours × elapsedMonths) - ytdConsumed (Year To Date Consumed)

  Positive = hours billed but not consumed (profit so far).
  Negative = consumed more than billed (loss so far).


──────────────────────────────────────────────────────────────
9. SURPLUS HOURS  →  displayed as "+12,8h"
──────────────────────────────────────────────────────────────

  surplusHours (Surplus Hours) =
    round( (totalClientHours (Total Client Hours) - projectedYearEnd (Projected Year End)) × 10 ) / 10

  = the hours the firm is projected to have left (profit) at year end.

  Positive → firm will finish the year under the client contract.
  Negative → firm is projected to exceed the client contract.


──────────────────────────────────────────────────────────────
10. SURPLUS PERCENTAGE  →  displayed as "+13.3%"
──────────────────────────────────────────────────────────────

  surplusPct (Surplus Percentage) =
    round( (surplusHours / totalClientHours (Total Client Hours)) × 1000 ) / 10

  (Multiply by 1000 then divide by 10 gives 1-decimal rounding.)

  Example:
    surplusHours     = 12.8h (12.8 Hours)
    totalClientHours = 96h   (96 Hours, Total Client Hours)
    surplusPct = round(12.8 / 96 × 1000) / 10
               = round(133.33) / 10
               = 133 / 10
               = 13.3%


──────────────────────────────────────────────────────────────
11. FINANCIAL RATE  (intermediate, not displayed directly)
──────────────────────────────────────────────────────────────

  financialRate (Financial Rate) =
    financialBudget / totalClientHours (Total Client Hours)

  = Tunisian Dinar (TND) value of one billable hour under the contract.

  Example:
    financialBudget  = 3 456 TND (Tunisian Dinars)
    totalClientHours = 96h (96 Hours)
    financialRate    = 36 TND/h (36 Tunisian Dinars per Hour)


──────────────────────────────────────────────────────────────
12. EST. FINANCIAL IMPACT  (Estimated Financial Impact)  →  displayed as "+450 TND"
──────────────────────────────────────────────────────────────

  surplusTND (Surplus in Tunisian Dinars) =
    round( surplusHours × financialRate (Financial Rate) )

  = monetary value of the hour surplus (profit) or deficit (loss)
    expressed in Tunisian Dinars (TND).

  Example:
    surplusHours  = 12.8h (12.8 Hours)
    financialRate = 36 TND/h (36 Tunisian Dinars per Hour)
    surplusTND    = round(12.8 × 36) = round(460.8) ≈ 461 TND
                    (exact value depends on live data)


──────────────────────────────────────────────────────────────
13. HEALTH / STATUS LABEL  →  "At Risk" / "Profitable" etc.
──────────────────────────────────────────────────────────────

  Per-client health badge (coloured dot):
    avgPace (Average Pace) > 1.00  → "red"    (Over Budget)
    avgPace (Average Pace) > 0.85  → "yellow" (At Risk)
    avgPace (Average Pace) ≤ 0.85  → "green"  (On Track)

  Year-end profitability badge:
    surplusHours > 0  → "Profitable"
    surplusHours ≤ 0  → "At Risk" / "Loss"

  Per-month status badge:
    consumed[m] > clientHours   → "over"    (exceeds client contract)
    consumed[m] > internalHours → "warning" (exceeds internal budget)
    otherwise                   → "good"


════════════════════════════════════════════════════════════════
COLLAB (COLLABORATEUR) COST CALCULATIONS  (Financial tab)
════════════════════════════════════════════════════════════════

  cost per entry  = entry.hours × Expert.coutHoraire (Coût Horaire / Hourly Cost)

  totalCostConsumed (Total Cost Consumed) =
    SUM( cost per entry )  rounded to nearest integer

  collab (collaborateur) share (%) =
    (collab.cost / totalCostConsumed (Total Cost Consumed)) × 100

  costVsBudgetPct (Cost Versus Budget Percentage) =
    (totalCostConsumed (Total Cost Consumed) / financialBudget) × 100


════════════════════════════════════════════════════════════════
QUICK REFERENCE — ALL DISPLAYED VALUES
════════════════════════════════════════════════════════════════

  Avg Pace (Average Pace)                    = SUM(paceRatio[m]) / elapsedMonths  × 100  %
  YTD Consumed (Year To Date Consumed)       = SUM(consumed[m])  for m ∈ [Jan..now]
  YTD Client Gain (Year To Date Client Gain) = (clientHours × elapsedMonths) - ytdConsumed
  Year-end proj. (Year-End Projection)       = ytdConsumed + (avgPace × internalHours × remainingMonths)
  Billed to client                           = clientHours × 12
  Surplus hours                              = totalClientHours - projectedYearEnd
  Surplus %  (Surplus Percentage)            = surplusHours / totalClientHours  × 100
  Est. financial impact (Estimated Financial Impact in TND) = surplusHours × (financialBudget / totalClientHours)
  Health label                               = avgPace > 1 → red | > 0.85 → yellow | else green
  Profitability label                        = surplusHours > 0 → Profitable | else At Risk


════════════════════════════════════════════════════════════════
ROUNDING RULES
════════════════════════════════════════════════════════════════

  Hours values (h / Heures)  → 1 decimal place  (French locale: comma separator)
  Percentages  (pct)         → 1 decimal place
  TND currency (Tunisian Dinars) → nearest integer  (round())
  Pace ratio                 → stored as float, displayed as integer %
